# 音效：合成兜底 + 可选的真实采样包

默认**不需要任何文件**：`src/journey/audio.js` 用 Web Audio 合成全部声音，
并按**车型**（CR400BF / CRH5 / CRH380BG / CR200J）与**车站**（枢纽 / 小站）
改变音色和播报。站名播报优先用浏览器自带的中文 TTS，所以每个站念出来的站名不同。

## 方式一：面板里载入音效包（推荐）

在 `journey.html` 左侧「声音」组点 **载入音效包**，多选你**已获授权**的音频文件。
文件只在本地解码，存进浏览器 IndexedDB，不上传、不进仓库；下次打开自动恢复。
支持 `.wav` / `.mp3` / `.ogg` / `.m4a`，单文件 ≤ 48 MB。

文件名决定用途（包含关键词即可，不必完全一致）：

| 关键词 | 用途 |
| --- | --- |
| 鸣笛 / 汽笛 / 风笛 / horn | 司机鸣笛 |
| 开门 / 车门开 | 开门提示 |
| 关门 / 闭门 / 车门关闭 | 关门警示 |
| 放气 / 排气 / 风缸 / hiss | 风缸排气 |
| 出站 / 发车 / 驶出 | 发车 |
| 进站 / 到站 / 停稳 / 抵达 | 进站停稳（整段优先） |
| 广播 / 播报 / 报站 / 提示音 | 站台广播 |
| 道岔 / 过岔 / 钢轨 / 轮轨 | 过岔 / 轮轨 |
| 制动 / 刹车 / 停车 | 制动排风 |
| 人群 / 候车 / 站台 / 嘈杂 / 环境 | 站台人群 |
| 行驶 / 运行 / 车厢内 / 车轮 / 轰隆 | 车内运行环境 |

**按车型 / 车站限定**：文件名里带车型或站名就只作用于它，否则全局通用。

- `CRH5鸣笛.wav` → 只有 CRH5A/G 用这段鸣笛，CR400BF 仍走合成。
- `哈尔滨西站广播.wav` → 只有在哈尔滨西（`name` 为「哈尔滨西」）时使用。
- `哈尔滨西CRH5进站.wav` → 两者都匹配时优先。

查找顺序：`站名+车型` → `站名` → `车型` → 全局 → 合成。
同名多条会随机取一条，避免每次进站都一模一样。

来源参考：爱给网「冰葡萄团队」的《高铁/动车/火车/地铁》专辑
（<https://m.aigei.com/sound/class/huo_che_ch_28/>）。

> 没有授权文件时，合成音效与 TTS 播报完全可用。

## 方式二：随源码打包

把文件放进本目录，构建时由 Vite 打包，运行时优先使用：

```
src/journey/audio/horn.wav                全局鸣笛
src/journey/audio/crh5/horn.wav           仅 CRH5
src/journey/audio/crh5/door-close.wav     仅 CRH5 关门
src/journey/audio/哈尔滨西/announce.wav    仅哈尔滨西广播
```

目录名用**车型 key**（`cr400bf` / `crh5` / `crh380b` / `cr200j`）或**站名**
（与 `zone.name` 一致，如「哈尔滨西」）。文件名用上表的英文 key 或中文关键词均可
（`announce` / `door-close` / `horn` / `arrive` / `depart` / `crowd` / `brake` / `switch`）。
本目录为空时不会产生任何音频资产。
